Stage CODE load base = **0x00232000** (file_offset = VA − 0x00232000).

**GUITAR MAP quirk:** absolute symbols for sidescrl/scrlcoll/compress in
`GUITAR/A.MAP` sit **+0x10** into the real function body (past the 8-instruction
prologue `mov.l r8..r14 / sts.l pr`). Corrected VA = MAP_VA − 0x10. MAUSO and
FINALE MAP VAs match Capstone prologues byte-for-byte.

Code identity (excluding trailing literal pools that hold stage-local BSS/ROM
addresses): DecompTile / DrawMap / LoadCDB bodies are **byte-identical** across
MAUSO ↔ GUITAR(corrected) ↔ FINALE. TileHeapInit is fully identical including
pools that only reference loader `malloc@0x204b30`. InitGetFloor / DecompByte
differ only in relocated absolute addresses.

2. tagMAP_DEF / tagTILE_DEF field map (from SH-2 offsets)
================================================================================

Inferred from LoadCDB / DecompTile / DrawMap / TileHeapInit / InitGetFloor.
Sizes are SH-2 pointer = 4 B; BE16 fields zero-extended before store into s32 slots.

### 2.1 tagMAP_DEF (r4 to almost every sidescrl fn)

| Off | Access pattern | Role |
|----:|----------------|------|
| +0x04 | LoadMap stores malloc result | cell / tile-index table pointer |
| +0x0c | TileHeapInit arg r6; DecompTile dst base; LoadCDB blit dst | VRAM/heap tile pixel base (`uint8 (*)[8][8]` in mangled TileHeapInit) |
| +0x12 | LoadCDB stores TileVallocStatic return (u16) | allocated tile slot / bank id |
| +0x14 | TileHeapInit stores malloc(count*2) | secondary heap bookkeeping |
| +0x18 | TileHeapInit stores count (u16) | heap capacity |
| +0x1c | LoadCDB ← CDB[+8] | tile/payload count |
| +0x20 | DecompTile reads | non-NULL → “heap mode” (src offset +0x88 vs +0x48) |
| +0x44 | DrawMap / LoadMap mode word | 4 = small-map path; 6 = skip LoadBitMap chain; ≤3 = DrawMap no-op |
| +0x50 | DrawMap | scroll/window X-ish (minus 4, >>2) |
| +0x54 | DrawMap | scroll/window Y-ish (minus 4, >>2) |
| +0x58 | InitGetFloor | **width** (column count for floor array) |
| +0x5c | InitGetFloor | **height** (start Y walk-down) |
| +0x68 | LoadMap reads CDB-derived | plane pixel_w (raw) |
| +0x6c | | plane pixel_h (raw) |
| +0x70 | | pixel_w >> 3 (tile columns) |
| +0x74 | | pixel_h >> 3 (tile rows) |
| +0x68/+0x6c | also DrawMap mode==4 uses these as blit args | |
| +0x70 | DrawMap else-path | primary blit extent (clamped ≤12) |
| +0x74 | DrawMap else-path | secondary extent (clamped ≤9) |

### 2.2 tagTILE_DEF (r5 to DecompTile)

| Off | Role |
|----:|------|
| +0x02 | BE16 width-related (`w`); scaled `w<<12` as DecompByte length/pitch arg |
| +0x06 | BE16 flags; `0xFFFF` = skip (already decompressed / empty); else index into heap (`flag<<12` byte offset) |
| +0x48 | compressed payload (no-heap mode) |
| +0x88 | compressed payload (heap mode, when map[+0x20] ≠ 0) |

3. Algorithms (MAUSO SH-2 → pseudocode)
================================================================================

### 3.1 `_TileHeapInit(map, count, pixels)` @ 0x2a13e4  (size 0x38)

```
map[+0x18] = (u16)count;
map[+0x0c] = pixels;                 // caller-supplied 8×8 tile RAM
buf = malloc(count * 2);             // loader _malloc @ 0x204b30
map[+0x14] = buf;
*buf = (u16)(count | 0x8000);        // high bit marks heap live
```

### 3.2 `_DecompTile(map, tile)` @ 0x2a141c  (size 0x6c)

```
flag = *(u16*)(tile + 6);
if (flag == 0xFFFF) return;          // sentinel

w = *(u16*)(tile + 2);
dst = *(u8**)(map + 0x0c) + (flag << 12);   // 4096 B per tile index
len = (w << 12);                             // passed in r6 (DecompByte ABI)

if (*(void**)(map + 0x20) != NULL)
    src = tile + 0x88;               // heap / streamed form
else
    src = tile + 0x48;               // packed form

DecompByte(src);                     // @0x2a0b4c; uses global dest ptr
// r4=src, r5=dst, r6=len on entry to jsr (SH delay-slot setup)
```

Pool: `[0xFFFF, &_DecompByte, imm 0x0088]`.

### 3.3 `_DecompByte` @ 0x2a0b4c  (size 0x4ec) — compress.o

Custom bitstream tile decompressor (not raw RLE1).

Prologue:
```
dst = *DEST_GLOBAL;          // MAUSO: word @0x2a0b8c → 0x002c88a0
jmptab = 0x2a0b94;           // 16 entries (nibble → handler)
```

Bit pump (simplified from first block):
```
load next control byte into high bits of r1 (<<16, <<8);
for bit = 0..7:
  r1 <<= 1;
  if (carry == 0):
      *dst++ = *src++;       // literal
  else:
      code = read_be16(src); src += 2;
      nibble = code & 0xF;
      jmp jmptab[nibble];    // match/copy handlers 0..15
```

Jump table (MAUSO):
```
0x2a0bd4 0x2a0bf4 0x2a0c10 0x2a0c32
0x2a0c5e 0x2a0c90 0x2a0cc8 0x2a0d06
0x2a0d4a 0x2a0d94 0x2a0de4 0x2a0e3a
0x2a0e92 0x2a0ef0 0x2a0f58 0x2a0fc2
```
Handlers decode length/distance variants (back-reference into already written
tile bytes). Full per-nibble semantics still open for host bit-exact port;
host `scrl_map` currently blits TIL as soft decode, not this engine.

### 3.4 `_DecompAddTile(map, tile)` @ 0x2a1488  (size 0x54)

Ring-queue of pending (map,tile) pairs before flush:
```
idx = *Q_HEAD;                       // @0x2c8888
slot = Q_BASE + idx * 8;             // @0x2c88a4, stride 8
next = idx + 1;
if (next > 0xC8) next = 0;           // wrap 200 entries
if (next == *Q_TAIL)                 // @0x2c8884
    DecompTile(map, tile);           // queue full → decompress immediately
else {
    slot[0] = map; slot[1] = tile;
    *Q_HEAD = next;
}
```

### 3.5 `_LoadCDB(map, file_id)` @ 0x2a1d38  (size 0xfc)

```
cdb = CD_Read(file_id, /*flags*/0);  // @0x2030f0 (loader GFS/CD helper)
n   = *(u16*)(cdb + 8);
bank = TileVallocStatic(map, n);     // @0x2a1334
*(u16*)(map + 0x12) = bank;

dst = *(u8**)(map + 0x0c) + (bank << 12);
MemcpyLike(dst, cdb + 10, n << 12);  // @0x2042c8 — may be raw or pre-sized

map[+0x1c] = *(u16*)(cdb + 8);       // n
map[+0x58] = *(u16*)(cdb + 0);       // pix_w
map[+0x5c] = *(u16*)(cdb + 2);       // pix_h
map[+0x60] = pix_w >> 3;             // tile columns
map[+0x64] = pix_h >> 3;             // tile rows
map[+0x68] = *(u16*)(cdb + 4);       // tw-ish
map[+0x6c] = *(u16*)(cdb + 6);       // th-ish

map[+0x70] = min(map[+0x68], 12);    // DrawMap clamp
map[+0x74] = min(map[+0x6c], 9);

FreeHelper(cdb);                     // @0x204b50
NullHelper(0);                       // @0x204b60
```

**CDB on-disk header (BE16) — matches host `scrl_cdb_parse` A-style:**

```
+0  pix_w     (e.g. MAUSO 1176)
+2  pix_h     (e.g. MAUSO 608)
+4  param_a   (clamped ≤12 → DrawMap)
+6  param_b   (clamped ≤9)
+8  tile_n    (TileVallocStatic count; payload bytes ≈ n<<12)
+10 payload…
```

B-style CDBs (VORTEX flags=0x0200…) are consumed by the same loader; host
already branches on w0 range.

### 3.6 `_LoadMap(map, layer)` @ 0x2a1c78  (size 0x8c)

```
cells = BuildCellCount(map[+0x68], map[+0x6c]);  // @0x213edc
tab   = malloc(cells << 2);                       // @0x204b30
map[+0x04] = tab;
SH2FillBuffer(tab, cells, 0);                     // @0x2a1038 zero-fill

if (map[+0x44] == 6) return;                      // already resident

ptr = LoadBitMapPath(layer);                      // @0x2030f0
// walk linked records: each record { u16 size_at_+0; u16 id_at_+2; ... }
for (i = cells-1; i != (u32)-1; --i) {
    id = *(u16*)(ptr + 4);
    tab[id << 2 / 4] = ptr;                       // index by id
    ptr = (u8*)ptr + *(u16*)ptr;                  // advance by size
}
```

### 3.7 `_DrawMap(map)` @ 0x2a19f4  (size 0x64)

Thin wrapper → `_AddTiles` @ 0x2a1570:

```
if (!map) return;
mode = map[+0x44];
if (mode <= 3) return;

if (mode == 4) {
    // small / DrawSmallMaps path
    AddTiles(map, /*r7*/map[+0x68], /*r6*/0, /*r5*/0, /*stack*/map[+0x6c]);
} else {
    x = (map[+0x54] - 4) >> 2;
    y = (map[+0x50] - 4) >> 2;
    AddTiles(map, map[+0x70], x, y, map[+0x74]);
}
```

Multi-layer parallax (A near → D far, factors 1/2/3/4) is applied by
`CheckScroll` / `InitMaps` / `DrawSmallMaps` callers that adjust map[+0x50/54]
before each `DrawMap` — not inside DrawMap itself.

### 3.8 `_SCRLCOLLInitGetFloor` @ 0x2a2e6c  (size 0x7c)

```
map = **(tagMAP_DEF***)0x2c87b8;     // active map def indirection
w   = map[+0x58];                    // width in columns
h0  = map[+0x5c];                    // start height

*_pFloorHixels = malloc(w << 2);     // array of s32 floor Y per column

for (x = 0; x < w; x++) {
    y = h0;
    while (y != 0) {
        if (MAPGetHixel(x, y) == 0) break;   // @0x2a3016 — empty cell
        y--;
    }
    pFloorHixels[x] = y;
}
```

Pools: `0x2c87b8`, `_pFloorHixels@2d43a0`, `_malloc@204b30`, `_MAPGetHixel@2a3016`.

### 3.9 `_SCRLCOLLGetHixel3D(x,y)` @ 0x2a2ee8  (size 0x24)

```
sc = RENDgetSCxy();                  // loader @0x2078c0 → {screen_x, screen_y}
return SCROLLGetHixel(sc->x, sc->y); // @0x2a3000 (scrlghix.o)
```

### 3.10 `_SCRLCOLLfindfloor(x, y)` @ 0x2a2f0c  (size 0x60)

```
// r10 = &_SCROLLGetHixel
delta = 0;
h = SCROLLGetHixel(x, y);
if (h == 3 || h == 1) {              // solid / floor class
    do {
        y -= 2; delta -= 2;
        h = SCROLLGetHixel(x, y);
    } while (h == 3 || h == 1);
} else {
    do {
        y += 2; delta += 2;
        h = SCROLLGetHixel(x, y);
    } while (!(h == 3 || h == 1));
}
return delta;                        // r0
```

`findceiling` / `findtop` are the vertical mirrors (same size class 0x54 / 0x40).

Hixel classes observed: **0** empty (InitGetFloor stop), **1** and **3** solid
for findfloor (matches pan-coll solid=3 convention elsewhere).

### 5.4 `_StartLick__7CGBonesP10LickStruct(this, lick)` @ 0x2611a0

Object field offsets (from imm pool):

| Off | Use |
|----:|-----|
| +0xa4 | current LickStruct* |
| +0xa8 | active flag / secondary lick ptr |
| +0xac | state word (set 1 on start, 0 on fail path) |
| +0xb0 | scratch |
| +0xb4 | anim/state const 0x0c80 written on arm |
| +0xb8 | bones sub-object for message |
| +0x44 | passed to memcpy-class helper with lick[+8] |

Flow:
1. If `this[+0xa4]` set → `StopLick(this, old)`.
2. If `this[+0xa8]` set and ≠ new lick → sound/FX cancel (`@262a60`).
3. Branch A (already armed): reset counters, `ObjNewBrain`-class `@205b24` /
   `@205ba8`, clear `*(0x283c20)`, optional message `@261c28`.
4. Branch B (cold start): bank `@24c0a0`, probe `@262a0c`; on success
   `ObjNewBrain(this, stub@261690)` via `@205168`.
5. Copy lick payload into `this[+0x44]` (`@271608`, 0x20 bytes).
6. Spin on Saturn status `@200e40` until ready (r9=0x7f sentinel).

### 5.5 `_StopLick__7CGBonesP10LickStruct(this, lick)` @ 0x2612e8

```
if (this[+0xa4] != lick) return;
wait status @200e40;
clear this[+0x44] region via helper @271608;
this[+0xb0] = 0; this[+0xac] = 0;
this[+0xb4] = 0x0140;            // idle const
```

### 5.6 `_Brain__7CGBones` @ 0x261368 (0x3c8)

Frame brain: allocates 40 B frame locals, seeds timer fields (100, etc.),
then drives lick / seaskel interaction. Cross-refs StartLick/StopLick and
