# mr-bones-port

Windows port of *Mr. Bones* (Sega Saturn, USA, MK-81016 V1.000) built on an own SH-2 runtime.
No game data is included or distributed: you provide your own two discs.

Status (2026-11-06): steps 1 and 2 of the plan are in place (data selection, identity check,
disc reading). The SH-2 core, hardware, presentation and the RUNWAY proof are **not started**.
See `docs/componentes.md` and `docs/coverage.md`.

## Build (Windows, clang + Ninja, as verified on this machine)

```
cmake -S . -B build -G Ninja ^
  -DCMAKE_C_COMPILER="C:/Program Files/LLVM/bin/clang.exe" ^
  -DCMAKE_RC_COMPILER="C:/Program Files/LLVM/bin/llvm-rc.exe" ^
  -DCMAKE_MAKE_PROGRAM="<VS BuildTools>/Common7/IDE/CommonExtensions/Microsoft/CMake/Ninja/ninja.exe"
cmake --build build
ctest --test-dir build
```

## Choose the discs and verify them

Paths are configurable; precedence is defaults < `mrbones.ini` < environment < command line.

| Setting | ini key | Environment | CLI |
|---|---|---|---|
| Disc 1 (`.cue` or `.bin`) | `disc1` | `MB_DISC1` | `--disc1` |
| Disc 2 | `disc2` | `MB_DISC2` | `--disc2` |
| Derived data | `data_dir` | `MB_DATA_DIR` | — |
| Saves | `save_dir` | `MB_SAVE_DIR` | — |
| Version manifest | `manifest` | `MB_MANIFEST` | `--manifest` |
| Config file | — | `MB_CONFIG` | `--config` |

Default config: `%LOCALAPPDATA%\MrBonesPort\mrbones.ini`.

```
build\mbverify --disc1 "D1.cue" --disc2 "D2.cue" --quick          # IP.BIN + core files
build\mbverify --disc1 "D1.cue" --disc2 "D2.cue" --full --save-config   # all files + Track 01 hash
```

Exit codes: 0 verified, 2 identity mismatch (wrong disc, version or hash), 3 config or I/O problem.

## Manifest

`manifest/versions.txt` holds SHA-256, size and LBA for each file and for each Track 01 image.
It was generated by `tools/make_manifest.py` from the maintainer's dumps. It proves a disc matches
those dumps; it is not an independent redump database.
